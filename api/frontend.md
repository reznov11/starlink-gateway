**Страница авторизация**
* Верстка
* Форма авторизации
* Валидация формы
* Авторизация с помощью (KNOX) JWT токена
* Восстановление пароля


**Панел управления**
* Верстка
* Навигатор разделов
  - Список разделов с иконками
  - Нижняя секция с аватаркой сотрудника 
* Шапка
  - Название раздела
  - Иконки


**Раздел формы**
* Таблица с формами
  - Поле поиска
  - Название
  - Интеграция (Партнер)
  - Дата создания
  - Количество блоков
  - Создал форму (Сотрудник)
  - Троеточие список опции с иконками:
    - Предпросмотр
    - Редактировать
    - Удалить (Модальное окно подтверждения)
  - Кнопка создать форму
  * Констуктор компонентов формы:
      - Заголовок
      - Текстовый блок
      - Текстовое поле
      - Номер телефона
      - Выпадающий список филиалов
      - Выпадающий список Визовых карт
      - Выпадающий список кредитовых продуктов
      - Выпадающий список дебетовых продуктов
      - Кнопка
      - Радио кнопки
      - Чекбоксы
      - Видео
      - Картинка 
      - Кнопка предпросмотр 
      - Модальное окно предпросмотра
      - Кнопки сохранить или отменить


**Раздел партнеров (компаний)**
* Таблица партнеров
  - Поле поиска
  - Название
  - ИНН
  - Дата создания
  - Категория бизнеса
  - Контактное лицо
  - Троеточие список опции с иконками:
    - Редактировать (Модальное окно)
    - Удалить (Модальное окно подтверждения)
* Кнопка добавить партнера (Модальное окно)
  - Название
  - Логин
  - Номер телефона
  - Емейл почта
  - Домен
  - Контактное лицо (ФИО)
  - Категория бизнеса
  - ИНН
  - Активный
  - Кнопки добавить и отменить


**Раздел сотрудников**
* Таблица сотрудников
  - ID
  - ФИО
  - Должность
  - Почта
  - Телефон
  - Права доступа
  - Дата создания
  - Дата последнего входа
* Кнопка добавить сотрудника (Модальное окно)
  - Имя
  - Фамилия
  - Аватарка
  - Телефон
  - Локация
  - Дата рождения
  - Почта
  - Пароль
  - Должность
  - Пароль
  - Может авторизоваться
  - Активный
  - Права доступа (список)
  - Кнопки добавить и отменить


**Профиль сотрудника**
* Верстка
* Обновить профиль

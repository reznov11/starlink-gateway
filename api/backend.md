**Установить защиту**
* С сервисом могут общатся только домены которые в белом списке и со статусом ACTIVE.
* Партнер имеет уникальный ID с которым будет с нашим сервисом общаться.
* Партнер может создать заявку только если его ID совпадает с тем что у нас в БД, имеет активного аккаунта и его домен находится в белом списке также со статусом ACTIVE.
* Если от партнера получили запрос без защитного протокола HTTPS, ему не показываем форму и в целом не может создать заявки.
* В заявках строго не принимаем файлы так как со стороны УИБ запретили.
* Лимит на количество отправленных заявок, т.е. клиент на сайте партнера не может отправлять больше одну заявку в день на одном продукте.
